# P0.14 — Analyzer Default

Status: **FINAL VERIFIED — CONCRETE SLICE SPECIFICATION**

1. Identity: P0.14; Analyzer Default.
2. Objective: derive evidence-bound interpretation from approved raw research input.
3. Scope: URL/media/raw concept input, source classification, quality gate, duplicate/reuse check, extraction, fact/opinion/interpretation, evidence, angle, hook, virality/readiness output.
4. Sources: Analyzer addendum; Research Contract #10; Phase 4 SoT.
5. Dependencies: P0.11 Research; P0.12 insight; P0.02 authorization.
6. Architecture: Analyzer owns derived interpretation/run; Research owns raw input provenance/evidence.
7. Ownership: Analyzer run/output; no transfer of canonical source ownership.
8. Data model: analyzer run, input reference, classification, extraction, evidence, angle, hook, confidence/readiness output.
9. State: input → quality/duplicate gate → extraction → interpretation → persisted output.
10. API: submit input, run analysis, retrieve output and readiness/evidence metadata.
11. UI: input, quality, duplicate, processing, evidence, angle and readiness states.
12. Events: approved analysis-run events via event infrastructure.
13. Workers: analysis execution may be asynchronous and retry-safe.
14. Security: source access and workspace scope server-authorized; provider credentials isolated.
15. Configuration: approved analyzer thresholds only; no invented scoring policy.
16. Storage: raw source remains Research-owned; derived analysis is persisted with provenance references.
17. Observability: run/input/source/correlation identifiers and processing outcome.
18. Errors: invalid input, quality failure, duplicate/reuse, extraction failure and insufficient evidence.
19. Idempotency: retrying an analysis run must not duplicate logical outputs.
20. Tests: input, quality, evidence, angles, confidence/readiness and persistence.
21. Acceptance: output is derived, evidence-bound, attributable and reproducible from stored input references.
22. Gate: Research provenance remains canonical.
23. Checklist: [ ] input [ ] quality [ ] extraction [ ] evidence [ ] output [ ] persistence [ ] tests.
24. Exit: analyzer default locked.
25. Risks: losing provenance or treating interpretation as source truth.
26. Open Decisions: none introduced.
