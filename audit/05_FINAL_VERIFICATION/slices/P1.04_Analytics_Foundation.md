# P1.04 — Analytics Foundation

Status: **FINAL VERIFIED — CONCRETE SLICE SPECIFICATION**

1. Identity: P1.04; Analytics Foundation.
2. Objective: authoritative derived measurement layer.
3. Scope: event/metric ingestion, aggregation, reporting and provenance.
4. Sources: Analytics addendum; Phase 4 SoT.
5. Dependencies: P0.09 events; source-domain events/metrics; authorization/tenant boundaries.
6. Architecture: Analytics derives measurements; it does not own transactional source state.
7. Ownership: metric definitions/derived measurement output and reporting state.
8. Data model: event/metric input references, aggregation windows, derived metrics, report provenance.
9. State: ingestion → aggregation → derived/reportable output; source mutation is prohibited.
10. API: metric/report query and approved ingestion/application operations.
11. UI: reporting, loading, empty, error and access-denied states.
12. Events: consumes approved source events; does not redefine producer semantics.
13. Workers: aggregation/measurement jobs may be asynchronous and replay-safe.
14. Security: access control and tenant scope enforced server-side.
15. Configuration: approved metric/aggregation configuration only.
16. Storage: analytics-derived state is persisted separately from transactional source ownership.
17. Observability: metric/run/window/correlation identifiers and reproducibility metadata.
18. Errors: malformed event, aggregation failure and unauthorized access are explicit.
19. Idempotency: event ingestion and aggregation must tolerate duplicate/replayed events.
20. Tests: reproducible derivation, access control, tenant scope and no source-domain mutation.
21. Acceptance: same inputs reproduce the same derived measurement under the approved rules.
22. Gate: no transactional ownership transfer.
23. Checklist: [ ] ingestion [ ] aggregation [ ] provenance [ ] scope [ ] reproducibility [ ] tests.
24. Exit: analytics foundation ready.
25. Risks: duplicate events or cross-tenant aggregation.
26. Open Decisions: none introduced.
