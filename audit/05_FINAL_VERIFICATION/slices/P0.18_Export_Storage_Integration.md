# P0.18 — Export / Storage Integration

Status: **FINAL VERIFIED — CONCRETE SLICE SPECIFICATION**

1. Identity: P0.18; Export/Storage Integration.
2. Objective: render editor output into export artifacts with explicit storage lifecycle.
3. Scope: export job/render, StorageObject, download, retention and purge.
4. Sources: Export addendum; Storage Contract #7; production pipeline; approved roadmap.
5. Dependencies: P0.17 Editor; P0.08 Storage; P0.09 events.
6. Architecture: Export owns export job/output; Storage owns object lifecycle.
7. Ownership: export job/result state is Export-owned; object retention/purge is Storage-owned.
8. Data model: export job, render result/output reference, StorageObject and retention state.
9. State: requested → rendering → completed/failed; output enters Storage lifecycle after creation.
10. API: create/export/status/download operations across Export and Storage boundaries.
11. UI: export progress, success, failure/retry and download states.
12. Events: approved export completion/failure and StoragePurged events.
13. Workers: render/export worker with retry/DLQ where retryable.
14. Security: download is authorization/scope controlled.
15. Configuration: approved export settings and 48h Export/Editor media retention.
16. Storage: Export creates/uses StorageObject but does not own purge policy.
17. Observability: export job/output/object/correlation identifiers.
18. Errors: render failure, storage failure, expired object and unauthorized download.
19. Idempotency: retrying export must not create uncontrolled duplicate outputs.
20. Tests: editor→export, completion, object creation, download, retention, purge and parent-content survival.
21. Acceptance: export completion produces authorized retrievable output and respects 48h retention.
22. Gate: Export and Storage ownership verified before build.
23. Checklist: [ ] job [ ] render [ ] output object [ ] download [ ] retention [ ] purge [ ] tests.
24. Exit: export/storage integration locked.
25. Risks: duplicate output or premature purge.
26. Open Decisions: none introduced.
