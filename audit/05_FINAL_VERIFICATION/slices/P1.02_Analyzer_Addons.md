# P1.02 — Analyzer Add-ons

Status: **FINAL VERIFIED — CONCRETE SLICE SPECIFICATION**

1. Identity: P1.02; Analyzer Add-ons.
2. Objective: extend derived interpretation without duplicating Research ownership.
3. Scope: approved add-on analyzers, versioned runs, attribution, evidence binding, quality/confidence/readiness and persistence.
4. Sources: Analyzer authority; Research Contract #10; Phase 4 SoT.
5. Dependencies: P0.11 Research; P0.14 Analyzer Default.

7. Ownership: analyzer run/output only; Research remains canonical evidence authority.

9. State: queued/running/completed/failed according to approved analysis lifecycle.
10. API: select/run/read add-on analyzer operations.
11. UI: add-on selection, processing, evidence and readiness states.
12. Events: analysis run lifecycle events through P0.09.
13. Workers: asynchronous analyzer execution with retry/DLQ.
14. Security: workspace/tenant scope and permission enforced.
15. Configuration: only approved analyzer configuration.
16. Storage: derived outputs persist with source/evidence references.
17. Observability: run/version/source/correlation identifiers.
18. Errors: quality failure, provider/input failure, insufficient evidence and processing failure.
19. Idempotency: run retry and persistence must be duplicate-safe.
20. Tests: quality, confidence/readiness, evidence binding, attribution, versioning and persistence.
21. Acceptance: each output is reproducible and evidence-bound.
22. Gate: no canonical Research state duplication.
23. Checklist: [ ] definition [ ] run [ ] evidence [ ] readiness [ ] persistence [ ] tests.
24. Exit: add-on analyzer boundary ready.
25. Risks: derived output detached from evidence.
