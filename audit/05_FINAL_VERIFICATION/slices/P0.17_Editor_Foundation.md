# P0.17 — Editor Foundation

Status: **FINAL VERIFIED — CONCRETE SLICE SPECIFICATION**

1. Identity: P0.17; Editor Foundation.
2. Objective: provide persistent editing state for approved production assets/blueprints.
3. Scope: canvas, timeline, layers/tracks, text, image, video, audio, transform, trim, blueprint mapping, asset placement, save/reload.
4. Sources: Editor addendum; Blueprint; Storage; production pipeline.
5. Dependencies: P0.15 Blueprint; P0.16 Asset Preparation; P0.08 Storage.
6. Architecture: Editor owns editing state, not source/evidence or export job state.
7. Ownership: canvas/document/timeline/layer editing state and revisions.
8. Data model: editor document, canvas, timeline, layers/tracks, asset mappings and revision state.
9. State: editable/saved/reloaded with conflict handling per implementation authority.
10. API: open/save/update editor document and asset mapping operations.
11. UI: canvas/timeline/layer controls, save/reload, loading/error/conflict states.
12. Events: approved editor state events; export events belong to Export.
13. Workers: none mandatory for core editing; heavy work follows approved async boundary.
14. Security: workspace/tenant/permission scope server-enforced.
15. Configuration: approved editor capabilities only.
16. Storage: media/object lifecycle remains Storage-owned; editor references objects.
17. Observability: document/revision/correlation identifiers.
18. Errors: missing asset, invalid mapping, stale revision and save failure.
19. Idempotency: saves/retries must avoid duplicate or stale document state.
20. Tests: blueprint open, asset mapping, edit, timeline, persistence and reload.
21. Acceptance: editing state persists and reloads without taking ownership of source or export.
22. Gate: editor/export/storage boundaries verified.
23. Checklist: [ ] document [ ] canvas/timeline [ ] asset mapping [ ] save/reload [ ] conflict [ ] tests.
24. Exit: editor foundation locked.
25. Risks: stale document writes or media lifecycle coupling.
26. Open Decisions: none introduced.
