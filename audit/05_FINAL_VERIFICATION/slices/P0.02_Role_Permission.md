# P0.02 — Role / Permission

Status: FINAL VERIFIED SLICE SPECIFICATION

Objective: role assignment and server-side permission authorization with scope enforcement.

Authority: Core Contract #2. Role/Permission is authorization only; it never grants commercial entitlement.

Owned: Role, Permission, assignment and authorization decision. API/application boundary performs authorization before protected domain mutation. UI may hide unavailable actions but this is never the security control.

States/outcomes: allowed, unauthenticated, permission denied, scope denied. Audit privileged changes. Observability records actor/target/correlation without sensitive data. Tests cover admin/support/custom roles, denied API access, scope enforcement and direct API bypass.

Exit: authorization boundary locked and reusable by downstream slices.
